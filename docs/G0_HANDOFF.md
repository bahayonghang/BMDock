# G0 验收交接清单

摘自 2026-09-08 实施包。此处只是 P0 相关验收要求的原文摘录，不代表完整 60 项 AC，也不代表通过。当前实际状态以 `execution/status.json` 与 CI 证据为准。

## 当前与目标

已编写真实引擎能力发现与 create/read/append smoke 工具。进入 T05 桌面工程前还需固定协议与完整原文读取/写入边界、并发和异常退出结论，以及 ADR。

| ID | 验收要求 | 验证方法 |
|---|---|---|
| AC01 · 版本与来源 | 支持profile有固定版本/commit、工具链和来源；release与main不混用。 | 检查manifest与源码快照；拒绝未识别版本。 |
| AC02 · 真实MCP互操作 | 真实引擎完成握手、工具/资源/提示词发现、分页、schema及错误测试。 | 不mock进程；测试协商版本和schema差异。 |
| AC07 · 引擎数据所有权 | 桌面不直接写Basic Memory私有数据库或复制第二套权威索引。 | 静态依赖及写入通道审查。 |
| AC08 · 结果和落盘状态 | 业务结果、MCP错误、磁盘状态与检索状态分开；不假设所有成功为202。 | 覆盖版本各结果分支；延迟物化并查看UI。 |
| AC10 · Markdown保真 | 无意删除未知frontmatter/正文/链接不可发生；官方规范化单独呈现。 | Golden fixture对比源文、保存后文和批准差异。 |
| AC15 · 并发编辑 | 预设竞争时序中无静默覆盖；无法保障时禁用并发写模式而不虚报共编。 | base/local/remote三方测试及check-write窗口故障注入。 |
| AC16 · 写结果未知 | 超时/断连/取消后不盲重试非幂等写入。 | 丢响应但服务已接受，再重连查询，append不重复。 |
| AC17 · 正常退出 | 停止新写，处理在途请求，验证官方lifespan清理再退出。 | EOF/SDK close/Windows退出事件与延迟物化。 |
| AC18 · 故障恢复 | UI/engine强杀、睡眠恢复、磁盘故障都留下真实未完成状态和恢复办法。 | 故障注入后重启；不以后台重放掩盖未知结果。 |
| AC35 · 版本工具覆盖 | 21/27静态基线与运行时差异可解释；专用search/fetch不伪造身份。 | 普通桌面客户端负向测试及可用工具正向测试。 |
| AC36 · CLI/API叶子清单 | 命令域拆为实际用户子命令及公开API功能，不用大类隐藏遗漏。 | 逐项对照注册树与OpenAPI；有差异就追加任务。 |
| AC54 · 许可与依赖风险 | 有许可证归属、源代码交付判断、SBOM及漏洞处置记录。 | 许可/依赖扫描与人工审查；未确认高危阻断。 |
| AC58 · 能力漂移 | 上游工具/schema/命令变化能被发现；未知危险能力不自动放行。 | 修改fixture registry并验证CI阻断和UI标记。 |
| AC60 · 可交接文档 | 所有任务、AC、来源、版本和限制可追踪；文档状态与实现一致。 | 运行文档校验，并人工核对尚未验证项。 |

## 不可扩大已有证据的范围

正常退出后看到了文件，不代表强杀或丢响应时安全；单次 append 不代表并发写入安全；列出全部 MCP 工具不代表全部工具已成功执行；CLI 树包含子命令不代表管理命令已接入产品界面；Windows 探针运行成功不代表 Tauri 安装包验收。
