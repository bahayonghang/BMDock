This is preparation for C07, not an acceptance result. The user approved code
implementation and representative benchmarks while deferring the complete
428-cell matrix. No threshold or sample count is relaxed.

- C01 frozen v3 and `c01-baseline-coverage.json`: 280 valid samples, 16 measured
  cells, 412 pending. Direct-MCP timings include the developer probe path. RSS
  named `engine_peak_rss` is Windows venv-launcher-only; total engine RSS is open.

  not promote the old binary's results to current-revision evidence.

- C05/C06 own layout/search behavior and native evidence where authorized.
  C03 owns actual indexed query projection; accepted C01 envelopes establish
  upstream meaning but cannot prove the future desktop adapter.

## Final report must distinguish

1. Functional generated-fixture evidence through actual production dispatch.
2. Deterministic command counts, bounded rows and controlled async regressions.
3. Representative paired measurements with all samples and failed attempts;
   clocks, corpus, profile, mode, hashes and budgets must match.
4. Native viewport/zoom/keyboard/IME/screen-reader/presented-frame evidence, only
   if actually acquired. Browser/static/Node checks retain their own labels.
5. Deferred full matrix and inherited failures: later-task-before-G0 guard,
   102 unique preexisting IPC Clippy spans, G0–G7 unpassed and do-not-release.

Paired overhead uses `adapter warm p95 - direct warm p95` against
`max(50 ms, 0.25 * direct warm p95)` for each comparable scenario. A missing
baseline, failed threshold, differing clock semantics or unknown RSS remains
an explicit gap. A representative passing case does not close C03/C07 AC5/AC2
for the complete workload. Current UI p95 <=110% baseline and native 30-edit
50/100 ms gates remain unverified until their specific evidence exists.

The final report maps every parent criterion and C01–C07 result to a concrete
receipt or test. Code-ready, partial and UNVERIFIED are separate states. The
parent stays open while deferred acceptance remains; no archive, commit, push
or release-gate edits are authorized.

## Representative paired clock qualification

C03's host-only query driver compares its direct-owner and production-dispatch
lanes using the same outer Python JSONL roundtrip. Inner Rust times are diagnostic.
This is a matched representative control, not the historical C01 `Probe.raw`
clock; do not merge those distributions or assert unchanged clock conformance.
Keep C03/C07 performance acceptance partial even if the representative pair meets
its unchanged overhead threshold. Thirty label comparisons are functional
entity-filtered parity, not thirty fully timed workloads or mixed-kind native
search coverage. Source-shaped non-entity/above-one/unknown-total fixtures are
synthetic and must be labelled separately from actual engine captures.
